怎么用 How it works

01

单击抽牌 Click to draw

按当前默认牌阵立刻抽牌。先看到一叠牌在洗，洗完翻开。默认是三牌时间线。

Draws with the current default spread. You see a shuffle, then the cards flip. Default is the three-card timeline.

02

拖动记住位置 Drag to place it

位移过阈值只改坐标。松手后记住，刷新还在。拖过的这次不会抽牌。

Past the drag threshold, only position changes. It persists on release. A drag never counts as a draw.

03

右击扇形菜单 Right-click the fan

四种牌阵、上次结果、查看历史。浏览器自带菜单不会出现。卡面与今日一牌在设置页。

Four spreads, last result, and history. The browser menu is suppressed. Deck art and today’s card live in settings.

抽牌与 followup 走 Host 工具。你也可以直接说「帮我占卜」或敲 /lumina draw。结果出来后点「让 AI 解读」，当前会话基于已经抽好的牌写解读。

Draws and follow-ups go through Host tools. You can also say “give me a reading” or type /lumina draw. Ask AI to interpret sends a follow-up based on the cards already drawn.

  • lumina_draw按牌阵抽牌Draw a spread
  • lumina_today今日一牌，当天稳定Today’s card, stable for the day
  • lumina_list_spreads列出四种牌阵List the four spreads
  • lumina_lookup_card按 id / 中英文名查询Look up by id or name

一条命令装上 Install with one command

Host 与界面是同一个包。本机要有 dsh CLI。不要再跑第二条安装命令。

Host and UI ship in the same package. You need the dsh CLI. Do not run a second add command.

terminal
dsh plugin --profile web add github:shetengteng/dsh-lumina-tarot

然后执行 dsh web。用 dsh --profile web --dump-config 核对应出现 dsh-lumina-tarot 层。仓库根目录也可 dsh plugin --profile web add .。

Then run dsh web. dsh --profile web --dump-config should show a dsh-lumina-tarot layer. From the repo root you can also dsh plugin --profile web add ..

更新 Update

DSH 不会自动更新插件。GitHub 安装后执行下面命令，再重启 dsh web。

DSH does not auto-update plugins. After a GitHub install, run this, then restart dsh web.

terminal
dsh plugin --profile web update dsh-lumina-tarot

卸载：dsh plugin --profile web remove dsh-lumina-tarot。本地 add . 不走 update，改完源码后 pnpm build 再重启。

Uninstall: dsh plugin --profile web remove dsh-lumina-tarot. A local add . does not use update — pnpm build, then restart.
