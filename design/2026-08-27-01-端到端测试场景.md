## 0. 环境

```sh
# 仓库根
dsh plugin --profile web add .
dsh --profile web --dump-config | grep -i lumina
dsh web
```

- 本机已有 `dsh` CLI；web profile。
- 只执行 **一次** `add`，不要再装 Client。
- `dump-config` 里应有 `# == dsh-lumina-tarot`。
- 浏览器打开 Harness Web；准备一个空会话（或让插件自动建会话）。
- 测试前记下：DSH 壳主题 / 语言，方便确认插件没有改壳。

对照表（面板 vs 对话）：内部 `cardId`（如 `fool`）不会进解读文案，用 **牌位 · 牌名 · 正/逆** 核对。

## 1. 悬浮牌手势

### S1 外观

- [ ] 右下角是一张 **5:8.6 牌背**（约 48×83），不是图标、不是人偶。
- [ ] 看起来是牌的背面。

### S2 拖动不抽牌

1. 按住牌背拖过约 6px，在视口内松开。  
2. 刷新页面。

- [ ] 拖的这次没有提问框、没有洗牌。
- [ ] 没有浏览器默认菜单。
- [ ] 刷新后牌仍在拖过的位置。

### S3 单击进提问，不先出右击菜单

1. 左键点一下牌背（不要拖）。

- [ ] 出现提问框「写下你的问题」，**不是**扇形菜单。
- [ ] 无需长按。

### S4 右击扇形菜单

1. 右击牌背。

- [ ] 没有浏览器默认菜单。
- [ ] 贴牌出现扇形：四种牌阵 +「上次结果」+「查看历史」。
- [ ] 牌没有翻到正面。
- [ ] 菜单里 **没有** 卡面主题 / 今日一牌 / 重置位置。

## 2. 抽牌主路径

### S5 三牌抽牌 + 洗牌 loading

1. 设置 → Lumina 塔罗：动画强度 **完整**，默认牌阵可保持三牌。  
2. 单击牌背 → 写一个具体问题（例如「下一步工作该考虑什么」）→「去洗牌」。  
3. loading 期间再点一次悬浮牌。

- [ ] 立刻出现半透明面板 + 牌叠翻飞 +「洗牌中…」。
- [ ] 连点不会并行抽两次。
- [ ] 结果展示牌阵名、问题、按位排牌、正/逆、关键词。
- [ ] 情感 / 事业 / 建议可展开。

记下面板（S8 要用，先记再点解读）：

| 牌位 | 牌名 | 正 / 逆 |
|------|------|---------|
|      |      |         |
|      |      |         |
|      |      |         |

至少一张逆位；没有就「再洗一次」再记。

### S6 动画关闭仍出真牌

1. 动画强度改为 **关闭**。  
2. 再抽一次。

- [ ] 无翻飞，静态牌叠或「抽牌中…」，仍等待 Host。
- [ ] 结果是真牌（有牌名、正逆），不是假数据。

测完把动画改回 **完整**。

### S7 右击换阵再抽

1. 右击 → 点「十字」（或「单张指引」）。  
2. 提问框提交。

- [ ] 提问框显示刚选的牌阵。  
- [ ] 结果张数与该阵一致（十字 5 / 单张 1 / 三牌 3 / 凯尔特精简 7）。

## 3. 让 AI 解读（P4）

前置：S5 的结果面板还开着；**点解读前不要跟模型说话**。

### S8 解读对上面板牌名与正逆

1. 点「让 AI 解读」。  
2. 看当前会话里新出现的内容。

交给模型的那条（插件 followup）应类似：

```
请解读「<你的问题>」。遵守 lumina-interpret skill，禁止改牌或重抽。
<牌位> <牌名>（逆） · …
```

正位没有「（逆）」。牌名、张数、正逆必须与 S5 表一致。

然后看模型正文：

- [ ] followup 上的牌位 / 牌名 / 正逆 = 面板。
- [ ] 正文按这几张解，没有换成别的牌。
- [ ] 你标了逆的，正文按逆位讲。

### S9 解读过程没有另抽一套

从点「让 AI 解读」到回复结束：

- [ ] 对话里 **没有** 新的 `lumina_draw` / `lumina_today` 工具卡。
- [ ] overlay **没有** 再进洗牌。
- [ ] 正文没有「我重新抽了」「换了一套」，也没有第二套牌名。

可选：回复后再发「换一套再解」。预期拒绝重抽，或让你自己点悬浮牌，而不是立刻再调抽牌工具。

## 4. 对话工具

### S10 「帮我占卜」调 `lumina_draw`

新开一句（可与 S8 同一会话）：「帮我占卜」或「帮我看看最近的事业运」。

- [ ] 模型调用 `lumina_draw`（出现牌阵卡：牌位 + 正逆）。
- [ ] 工具结果里没有「你应该辞职」这类解读散文。
- [ ] 没有编造未抽到的牌 id。

（此项已人工验过可通过；回归时再跑一遍。）

### S11 今日一牌（对话或 slash）

1. 对模型说「今日一牌」，或输入 `/lumina today`。  
2. 同一自然日再执行一次。

- [ ] 走 `lumina_today` 或 `/lumina today`。  
- [ ] 同日两次结果稳定（同一张、同一正逆）。

## 5. 历史

### S12 上次结果

1. 关掉结果面板。  
2. 右击 →「上次结果」。

- [ ] 打开最近一次抽牌，牌面与刚才一致。

### S13 查看历史

1. 右击 →「查看历史」。

- [ ] 能看到此前记录；点一条能打开。

### S14 导出 JSON

设置 → Lumina 塔罗 → 导出 JSON。用文本编辑器打开下载文件。

- [ ] 能 `JSON.parse`。  
- [ ] 顶层有 `exportedAt`、`theme`、`history`；`history` 为数组。  
- [ ] 至少包含刚才抽过的记录（`spreadId` / `cards`）。

### S15 清空历史

1. 点「清空全部历史」。  
2. 确认文案应为：「将清空所有占卜历史与当前进行中的占卜，确定吗？」  
3. 确认后再打开「查看历史」。

- [ ] 必须确认才会清。  
- [ ] 清空后列表为空。  
- [ ] 「上次结果」失败或提示没有结果。

## 6. 设置

全程确认：**改插件主题时，DSH 壳 Appearance 不变**。

### S16 主题只染插件

1. 记下壳的明暗。  
2. 设置里把主题在 mystic / minimal / nature 间切换。

- [ ] 悬浮牌圆角 / 色调跟着变。  
- [ ] 壳 Appearance 不变。

### S17 卡面与牌背联动

1. 卡面选 **极简**：能看到牌背五种、小阿符号/几何。改牌背后看悬浮牌。  
2. 卡面选 **韦特** 或 **水彩**：牌背、小阿两组隐藏。  
3. 切回极简：牌背选项回来，先前选的牌背还在。

- [ ] 非极简时牌背 / 小阿隐藏。  
- [ ] 改牌背或卡面后，悬浮牌外观跟着变。

### S18 语言跟随 DSH

1. 「语言」选 **跟随**。  
2. 改 DSH 界面语言（中 / 英）。  
3. 再改为插件内「中文」或「英语」（不再跟随）。

- [ ] 跟随时，插件设置文案 / 牌面语言跟 DSH。  
- [ ] 不跟随时，只跟插件选项，不跟壳。

### S19 隐藏悬浮牌

1. 关掉「显示卡牌」。  
2. 再打开。

- [ ] 关掉后屏幕上没有牌背；slash / 对话工具仍可用。  
- [ ] 打开后牌背回来。

### S20 重置位置

1. 把牌拖到别处。  
2. 设置里点「重置」。

- [ ] 牌回到默认右下（约 0.92 / 0.82）。  
- [ ] 设置页没有 X/Y 数字输入。

## 7. 安装交付（P8，最后做）

### S21 安装核对（若本轮是新 add）

```sh
dsh --profile web --dump-config
```

- [ ] 出现 `# == dsh-lumina-tarot`。  
- [ ] 重启 `dsh web` 后右下仍有可拖牌背。

### S22 Headless / 非 web（抽检）

在没有 Web UI 的 profile 上装同一包（或本机已有 headless profile）：

- [ ] 进程无 UI 相关报错。  
- [ ] `lumina_draw` / `lumina_today` 仍注册（对话或 dump / 工具列表能看到）。

### S23 卸载

```sh
dsh plugin --profile web remove dsh-lumina-tarot
```

重启 `dsh web`（或刷新已开页）：

- [ ] 悬浮牌背消失。  
- [ ] 设置侧栏没有「Lumina 塔罗」。  
- [ ] 对话里没有 `lumina_*` 工具。

卸载 **不会** 自动清历史 JSONL 和 settings。要连数据一起去掉，须在卸载前做 S15。
