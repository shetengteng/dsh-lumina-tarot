## P2 · 洗牌 loading + 抽牌结果

**目标**：单击后半透明面板 + CSS 牌叠 loading；展示结果 = `max(最短动画, Host 返回)`。

### 前置：session 镜像

- [x] overlay 为 root 作用域，在 `apply` 里镜像 `sessions.list.current`
- [x] 经 inject `hooks` 把当前 `sessionId` 传给 dock / panel（组件不直接碰 ctx）
- [x] 无当前会话时单击抽牌给出明确错误，不静默失败

### Host 领域（精简牌池即可）

- [x] `src/domain/spreads.json`：四种牌阵，id 与原 PWA 一致
- [x] `src/domain/cards.json`：至少 22 张大阿（P6 再扩到 78）
- [x] `drawCards(spread, reversedRate)`：默认 `reversedRate = 0.35`，**不** import Vue `@/`
- [x] 抽牌结果形状对齐 `ReadingRecord.cards`：`cardId` / `reversed` / `positionIndex`

### Host commands

- [x] 注册 `/lumina draw [spreadId]`：缺省用 settings `defaultSpread`
- [x] 注册 `/lumina today`：日期 seed，同日稳定
- [x] 将「当前结果」存在 Host（内存可，P7 再落 JSONL）
- [x] command 失败返回 `{ kind: 'error', text }`，不编假牌

### Client 洗牌 loading

- [x] `src/client/shuffle/`：CSS `@keyframes` 牌叠翻飞，参考 `ShuffleView.vue` 的 `shuffle-dance`
- [x] **不**引入 GSAP / tsparticles / Three.js
- [x] **不**做长按 3 秒圆环
- [x] 文案「洗牌中…」
- [x] 约 5–7 张牌背，`--i` 错相
- [x] `animationLevel = full`：最短约 1.6–2.0s
- [x] `animationLevel = lite`：最短约 0.7s，牌更少、位移更小
- [x] `animationLevel = off`：无翻飞，静态牌叠 +「抽牌中…」，仍等待 Host
- [x] 显示结果时机：`max(动画最短时长, command 返回)`
- [x] Host 先返回、动画未满：继续播完再揭晓
- [x] Host 失败：停动画，错误态 + 重试，**不**展示假牌
- [x] loading 期间禁用单击再抽、禁用「让 AI 解读」

### Client 结果相

- [x] 半透明遮罩：`rgba(0,0,0, panelOpacity)`，可 `backdrop-filter`
- [x] 展示牌阵名、按位排牌（5:8.6）
- [x] 单卡：正/逆位、关键词、核心含义；love/career/advice 可折叠
- [x] `full` / `lite` 可错开翻开；`off` 直接亮出
- [x] 「再洗一次」重新进入 loading 相
- [x] 关闭面板回到悬浮牌背

### 接线

- [x] 单击悬浮牌：`ctx.remote.commands.execute(sessionId, '/lumina draw …')` + 同时开 loading
- [x] 右击选牌阵：写入 `defaultSpread`，提问框提交后同一 command，带选中 `spreadId`
- [x] 「今日一牌」不进右击：`/lumina today` / `lumina_today`；结果页「再洗一次」可复用

### 验收

- [x] 无需长按
- [x] `off` 无翻飞仍出真牌
- [x] 失败无假牌
- [x] 连点不会并行两次抽牌
